GitHub Pages上で動作する静的ツールです。入力内容・生成プロンプト・Geminiの出力内容は利用者自身で確認してください。

使い方

基本の流れ

  1. 求人原稿URLまたは原稿全文を入力します。
  2. 対象企業の参考ページと、比較したい競合企業を最大2社まで入力します。
  3. 必要に応じてターゲットや文面方向を入力します。
  4. 「コピーしてGeminiを開く」を押します。
  5. 開いたGeminiの入力欄へ貼り付け、評価基準CSVを添付して送信します。Geminiから返されたJSONを手順5の欄へ貼り付けて検証し、エラー0件ならGAS用JSONをコピーします。

求人原稿の入力

URLだけでも実行できますが、CAPTCHAやログイン制限のあるサイトでは本文を取得できないことがあります。全文を貼り付けると安定します。

評価基準の渡し方

Geminiへプロンプトを送る際は、評価基準CSVだけを添付してください。JSON Schemaファイルは添付不要です。専用Gemで運用する場合は、評価基準CSVをGemの知識へ登録できます。

競合URLを入力した場合

競合企業は最大2社です。1社以上入力され、「競合他社との比較・自社の強み」が未記載なら、文面提案の1件目として扱う指示が適用されます。

JSON検証

Geminiの回答を手順5へ貼り付けると、必須No.、提案件数、案件ID、参照ソース、事実と仮説の混在、未確認制度の断定などを確認します。エラー0件になったらGAS用JSONをコピーできます。

出力の流れ

Geminiは分析結果をJSONで返します。GitHub PagesがJSONを検証してGAS用リクエストへ変換し、GASがテンプレートへ書き込んで、先方用3シート・社内用2シートのGoogle Sheetsを生成します。

詳細設定

提案数・文面長・Web調査範囲を案件ごとに変更できます。設定はブラウザへ保存され、「入力をクリア」を押しても維持されます。必要なときだけ「標準設定に戻す」を使用してください。

入力データ

入力内容はブラウザのローカルストレージに自動保存されます。共用PCでは作業後に「入力をクリア」を押してください。
